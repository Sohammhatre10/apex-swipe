# ApexSwipe

Tinder-style stock discovery app scaffold with:
- FastAPI + MongoDB backend (`backend/`)
- Next.js 14 frontend (`frontend/`)

## Backend quickstart

1. `cd backend`
2. Create `.env` from `.env.example`
3. `python -m venv .venv`
4. Activate venv and run `pip install -r requirements.txt`
5. `uvicorn main:app --reload`

## Frontend quickstart

1. `cd frontend`
2. Create `.env.local` from `.env.local.example`
3. `npm install`
4. `npm run dev`
